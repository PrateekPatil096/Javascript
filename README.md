# JavaScript Practice Repository

This repository is a collection of beginner-friendly JavaScript exercises organized by chapter. Each chapter folder contains a simple HTML page, a stylesheet, and a JavaScript file for practicing core JavaScript concepts.

## Overview

The project appears to be a learning repository focused on:

- JavaScript fundamentals such as variables, functions, and basic logic
- Small practice examples in separate chapter folders
- Asynchronous JavaScript concepts like closures, promises, and async/await
- Simple front-end examples that can be opened directly in a browser

## Repository Structure

Each chapter folder follows the same basic layout:

- index.html — the page structure
- style.css — styling for the example
- scrpit.js — the JavaScript practice code

Example folders include:

- ch_0
- ch_3
- ch_10
- ch_22

and the rest of the numbered chapter folders up to ch_22.

## How to Use

1. Open the chapter folder you want to explore.
2. Open index.html in your browser.
3. Review or edit the JavaScript in scrpit.js to experiment with the examples.

## Notes

This repository is intended for learning and practicing JavaScript step by step. A copy of Eloquent JavaScript is also included in the root folder as a reference.
